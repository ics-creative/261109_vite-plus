# Vite+入門 サンプル

ICS MEDIAの記事『[開発ツールをひとつにまとめる！ Vite+入門](https://ics.media/entry/261109/)』のサンプルです。Vite+のテンプレートを使い、ボタンをクリックするとカウンターが2ずつ増えるように変更しています。

## 実行方法

事前に[Vite+](https://viteplus.dev/)の`vp`コマンドをインストールしてください。

```bash
vp install
vp dev
```

表示されたURLをブラウザーで開くと、サンプルを確認できます。

## その他のコマンド

```bash
vp check  # フォーマット・リント・型チェック
vp test   # テスト
vp build  # ビルド
```
